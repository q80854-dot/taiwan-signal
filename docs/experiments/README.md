# 預先登錄的 Challenger 影子實驗

依 2026-11-12 外部審查報告 T.1：**先定義問題、主要終點與成功條件，再看資料**。

- 登錄（凍結）日：2026-11-12。此日（含）以前的資料屬「探索期」，假說就是看了這段資料才提出的，
  不得再用同一段資料當成採用依據。
- 樣本外（OOS）：2026-11-13（含）以後才產生的訊號。
- 主要終點：Champion 分批淨 R（僅已定案樣本），「留下組平均 − 基準平均」，以訊號日為叢集做拔靴。
- 判定所需：OOS ≥ 40 個訊號日、留下組 ≥ 200 筆已定案；最低經濟重要差異 0.05R。
- 門檻沿用系統既有分級，登錄後凍結；要改門檻必須另立新的實驗編號。
- 只評估、不採用：程式（`experiments.py`）不改正式訊號、不寫任何設定。`supported` 只代表可以提案，
  仍須人工審查回撤、尾端風險與可成交性，並經使用者同意。

E07～E10 來自 2026-11-12 的出場與相對強弱研究（`docs/research/EXIT_STUDY_2020_2026.md`）：重播顯示有改善的方向，
但各有未過關之處（靠極端值、近兩年效果消失、未過多重比較校正、事後才發現），所以不改正式策略，先登錄、
用 11-13 起的真實資料驗證。E07／E08 的資料在 `shadow_signals.alt_exits`，方案最長持有 60 天，定案較慢。

E04～E06 是 2026-11-12 Champion 變更（放空停發、做多須週線偏多、做多門檻 75）的「恢復觀察」：停發依據是
2020–2026 重播的樣本外證據，這三個實驗預先寫好「什麼情況下值得重新提案恢復」。同日起 E01／E02 的基準
（做多候選）也隨之只含週線偏多且 ≥ 75 分者——OOS 起算日（11-13）與新規則生效日相同，基準前後一致。
