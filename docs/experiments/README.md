# 預先登錄的 Challenger 影子實驗

依 2026-11-12 外部審查報告 T.1：**先定義問題、主要終點與成功條件，再看資料**。

- 登錄（凍結）日：2026-11-12。此日（含）以前的資料屬「探索期」，假說就是看了這段資料才提出的，
  不得再用同一段資料當成採用依據。
- 樣本外（OOS）：2026-11-13（含）以後才產生的訊號。
- 主要終點：Champion 分批淨 R（僅已定案樣本），「留下組平均 − 基準平均」，以訊號日為叢集做拔靴。
- 判定所需：OOS ≥ 40 個訊號日、留下組 ≥ 200 筆已定案；最低經濟重要差異 0.05R。
- 門檻沿用系統既有分級，登錄後凍結；要改門檻必須另立新的實驗編號。
- 只評估、不採用：程式（`experiments.py`）不改正式訊號、不寫任何設定。`supported` 只代表可以提案，
  仍須人工審查回撤、尾端風險與可成交性，並經使用者同意。
