## 0. 鐵律（不可違背）

1. **不碰策略/風控/Champion**：config_hash `d4eb06e13ef2` 不變；純視覺不改 API、DOM id、`data-*`、事件綁定、登入/權限與統計定義。每批附「保留/調整矩陣」。
2. **不造假、不掩蓋**：缺資料顯示「未取得／未知」空狀態，不以 0 或模糊數字裝飾；風險、虧損、缺值在**相關首個視野**可辨識，不藏 tooltip/展開。美編不得掩蓋 Upgrade Audit 口徑問題（資料修復另立工作）。
3. **技術前提**：`dashboard.html` 由 `send_from_directory` 送出（app.py，非 Jinja）→ **禁止加入 Jinja include**（會被當純文字送出）。登入頁樣式由 JS 插入，須測載入順序與 specificity。
4. 自動刷新不得重置使用者的展開/篩選/捲動/焦點；新 DOM 替換保留當前操作。
5. 深色模式與強制手機/桌面模式都要驗；圖表漲跌色沿用現有切換機制，不寫死紅綠。
6. 不以美編名義重算指標；新增「行為」與純 CSS 分開估工，逐項列資料契約與變更檔案。

## 2. 設計系統基礎（P1 第一刀，全站共用）

- **語意色三組固定 token**：品牌紫＝選取/導覽/CTA；漲跌紅藍＝價格/報酬（跟隨深淺色與使用者設定）；警示色＝系統狀態。三者不混用。
- **字級**：內文 14–16px、輔助 12–13px、區塊標題 16–20px、頁標 24–30px、關鍵數字 28–40px；數字 `tabular-nums`；依資訊密度驗證、不全域放大。
- **間距 token**：4/8/12/16/24/32/48/64px；表格與行銷頁採不同密度。
- **圓角**：首頁展示容器 16–24px；研究工作區 6–12px 或平面分隔；膠囊僅限主 CTA 與標籤。
- **層次**：背景／主要表面／內嵌表面三層；研究區以細線與表面色分區；陰影主要用於浮層；避免卡片套卡片。
- **基礎元件**：按鈕、頁標、卡片、表格、空/錯誤/stale/forbidden 狀態、浮層——先建元件再套頁面；每批只調一組元件，禁止疊大量 `!important`。
- 風格基調：暖灰背景、白卡、深色文字、紫色小範圍重點、紅色印章標誌；「有編輯節奏的財經研究工作台」。避免滿頁漸層/玻璃效果/光球/每卡發光/機械式每段三卡/過度行銷文案。

## 4. 動態規格（全部尊重 prefers-reduced-motion）

| 動態 | 設計值 | 限制 |
|---|---|---|
| 首屏進場 | opacity＋translateY 6–10px，280–360ms，至多兩組錯開 60–90ms | 每次進站一次；內容可立即操作 |
| 頁籤切換 | 150–200ms 淡入＋指示條平移 | 舊資料不得殘留在新標題下；綁 request/頁面狀態 |
| CTA 按壓 | 120–160ms，位移 1px 或背景變化 | hit area 不縮小；loading 狀態清楚；鍵盤可用 |
| 卡片 hover | 首頁互動卡 ≤2px / 180–220ms；研究區以背景/邊線變化 | 純指標卡不浮動；觸控不依賴 hover |
| 表格列/選取 | 背景 150ms；選取細線＋文字 | 數字位置不動；長表不逐列動畫 |
| skeleton | 低對比、近似最終內容 | 超時顯錯誤與最後快照；reduce-motion 用靜態 placeholder |
| 行情更新 | 僅確有新值時底色提示約 500ms | 不輪播虛構值；aria-live 只放必要摘要 |
| 圖表 hover | 十字線、tooltip、可固定選取 | tooltip 不裁切；觸控/鍵盤替代 |
| 滾動導覽 | 150–250ms 選擇性平滑 | 保留 URL 錨點/返回/sticky offset |
| Toast | 短淡入、非阻塞 | 重要錯誤持續可讀；不自動移焦 |

禁止：連續 requestAnimationFrame、為動畫新增背景輪詢、大模糊陰影、全頁 filter、報價逐位跳動、盈虧曲線持續重播；頁面隱藏時停止裝飾動畫。

## 5. 驗收矩陣（每頁必過）

1. 斷點 360/390/768/1024/1440px；淺/深色；200% 縮放；觸控；鍵盤；reduce-motion。
2. loading/empty/error/stale/forbidden 五態齊備；API 失敗數字不可變 0；風控警示不被裝飾壓低。
3. 觸控目標 44px 為設計目標；文字對比按 WCAG AA 量測；整頁無意外溢出（表格可局部橫滑）。
4. 流程驗證：未登入→Google 登入→回原頁、站主/一般會員、搜尋、頁籤、自選股、提醒、日期篩選、圖表、匯出。寫入一律測試環境，禁止對正式會員試改。
5. 效能：同裝置/同資料/同快取改前後各量 ≥3 次取中位數；動畫不可造成可見卡頓或大幅 Layout Shift；不編造達標數字。
6. 交付：可審閱 PR、可回退、tokens、前後截圖（去識別、標來源）、測試表；未驗證項列 blocked。

完成標準：每頁有修改位置、理由、保留項目、視覺證據與功能驗收結果。不只交新封面或整站重上色；不藉美編改策略、掩蓋虧損或新增無證據成效主張。
