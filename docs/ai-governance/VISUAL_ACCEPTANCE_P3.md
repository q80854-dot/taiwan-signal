## 3. 減少動態（reduce-motion）

- 整站全域關閉開關：`@media(prefers-reduced-motion:reduce){*{animation:none!important;transition:none!important}}`。
- P3-A/P3-B 所有新動態（CTA 按壓、互動卡 hover、行情 flash、loading 脈動、登入牆流程示意）皆包在 `prefers-reduced-motion:no-preference` 內。
- 實測：reduce-motion 下 `.btn` computed `transition-property: none`、登入牆流程示意動畫停用、暫停鈕隱藏。✅

## 4. 五態（loading / empty / error / stale / forbidden）＋ 誠實缺值

- 基礎元件 `.st`（P1-A）：五態齊備；loading 脈動尊重 reduce-motion。
- 誠實缺值：健檢 unknown／na（LIVE14）、未取得不以 0 裝飾（P1-B/C、B04/B05/B07）、run_id 與逐筆回撤/換手列為資料契約缺口（B04/§8.5）。✅
- API 失敗不變 0：持倉/績效/總覽/熱圖/影子等載入失敗顯示「未取得／載入失敗」而非 0。✅

## 6. 觸控 ／ 鍵盤（結構支援，建議人工複驗）

- 觸控：`.ts-tap`（44px 輔助類）提供；手機樣式多數控制項 ≥ 40px；觸控不依賴 hover（互動卡 hover 以 `@media(hover:hover)` 守門）。真機點擊命中建議人工複驗。
- 鍵盤：全站 `:focus-visible` 外框、Ctrl/Cmd+K 搜尋、搜尋下拉方向鍵/Enter、tab 順序沿用 DOM。螢幕報讀逐頁朗讀建議人工複驗。
